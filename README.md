## 👩‍💻 About This Fork

This is my personal fork of [Reactive Resume](https://github.com/amruthpillai/reactive-resume), maintained by **Harshitha R**.  
I'm exploring the codebase, understanding full-stack architecture, and planning to contribute improvements.

## ✨ Features

- 🖊️ Real-time resume preview as you type
- 📤 Export as PDF, JSON, or DOCX
- 🎨 Multiple professional templates
- 🤖 AI integration (Claude, OpenAI, Gemini)
- 🔒 Privacy-first — no tracking, no ads
- 🐳 Self-hostable with Docker
- 🌍 Multi-language support

## 🛠️ Tech Stack

| Category | Technology |
|---|---|
| Framework | TanStack Start (React 19, Vite) |
| Language | TypeScript |
| Database | PostgreSQL + Drizzle ORM |
| Styling | Tailwind CSS |
| Auth | Better Auth |
| State | Zustand + TanStack Query |

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/R-Harshitha06/reactive-resume.git
cd reactive-resume

# Start with Docker
docker compose up -d

# Open in browser
open http://localhost:3000
```
